# Laboratory Inventory Dashboard — SQL + Streamlit

**Author:** Diana Brito Hoyos — Biologist & Biostatistician | Data Analyst

🔗 **[Live demo](https://sql-lab-inventory-dashboard.streamlit.app/)**

An interactive dashboard for managing a laboratory's biological reference material inventory (stock levels, usage history, reactivation/expiration alerts), built with a **real SQL backend** (SQLite) rather than in-memory dataframe filtering.

> ⚠️ **Note on data:** All data in this repository is **fully synthetic**, generated by [`data/seed_data.py`](./data/seed_data.py). It is inspired by the general structure of laboratory reference-material inventories (categories, storage, movements, reactivation dates) but contains no real institutional, personal, or proprietary information.

---

## Why SQL, not just pandas

This project intentionally pushes logic into SQL rather than filtering dataframes in Python, to demonstrate applied intermediate SQL:

- **JOINs** — combining item metadata with movement history
- **Aggregations** — stock totals and counts by category
- **Window functions** — running stock balances (`SUM() OVER (PARTITION BY ... ORDER BY ...)`) and usage ranking (`RANK() OVER (PARTITION BY ...)`)
- **CTEs** (`WITH` clauses) — layering logic for readability (e.g. classify reactivation status, then aggregate)
- **Views** — a reusable `v_low_stock` view, queried directly by the dashboard

See [`queries/example_queries.sql`](./queries/example_queries.sql) for all example queries, commented and independently runnable.

## What the dashboard shows

- **KPIs**: total items, total stock, out-of-stock count, items due for reactivation soon
- **Stock by category** (bar chart) and **reactivation status breakdown** (pie chart)
- **Low stock alerts**, sourced from a SQL view
- **Recent movement history**, from an `INNER JOIN` between items and movements
- **Most-used items per category**, from a `RANK()` window function
- Category filter (sidebar) that re-parameterizes the underlying SQL queries

## Running locally

```bash
pip install -r requirements.txt
python data/seed_data.py       # generates data/inventory.db
streamlit run app.py
```
